- **Agent 的双重核心任务**：
  1. **全文高保真还原**：100% 忠实截图原文，绝不臆造、不缩减、不擅自主观修饰。
  2. **精确提炼 ET6601 变更点**：将所有针对 ET6601 的修改细节精确识别并独立汇总成章。

## 4. Agent 执行准则与质检验收标准

### 准则一：真实准确，绝对不拼凑、不臆造
1. **禁止缩略**：接口信号表（如 70+ 行总线信号）、寄存器字段表必须逐行完整列出，严禁截取前两行就省略。
2. **拒绝拼图感**：禁止把一堆大图接连塞在空白文档里。必须文字到哪里、图表就紧跟在对应章节下方。
3. **双页逻辑切分**：对 GameViewer 左右双页视图，必须按左页到右页的自然阅读逻辑依次转录，严禁左右文字横向串行。
4. **水印与控件剥离**：彻底过滤 `ETMCU huan.li` 录屏水印、底部翻页条（`屏幕X-Y，共Z个`）及推流参数（`UDP fps Mbps`），只提取属于文档正文的技术墨水。

### 准则二：ET6601 修改点提取深度与精度
1. **依据特殊视觉标记**：在原始设计图中，针对 ET6601 的内容通常采用下划线、彩色高亮或特定修订说明。Agent 必须敏锐捕捉这些特征。
2. **逐条结构化提炼**：
   - **变更位置**：标明所在章节与对应截图（如 `images/GameViewer_vUFYITp5T4.png`）。
   - **变更性质**：明确区分是【新增】、【修改】、【回退】还是【参数调整】。
   - **核心技术差异**：例如：
     - *存储配置变更*：新增 64KX72=512KB PFLASH，原有 FLASH 命名与回退为 DFLASH；
     - *时钟与分频*：时钟分频比例支持范围（如 1:1, 1:2, 1:6）；
     - *安全与写保护*：针对 ET6601 的 OTP 区域与写保护生效机制；
     - *寄存器映射*：新增或重定义的控制寄存器地址。
