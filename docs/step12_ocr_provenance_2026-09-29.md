47不是漏行数量，更不是准确率。有些观察可能是正常重识别替换后的旧条目；要判断资料缺失，需要源位置及前后阶段结果。这个检查的价值是避免逐页继续把后处理副作用误归因为模型能力。

复核命令：

```bash
python scripts/audit_post_layout_ocr.py work/full/restored/sarc -o work/post_layout_audit.json
```

脚本不运行OCR，不删除或补写任何文字，不修改源文件，输出必须位于缓存目录之外且不能覆盖既有报告。
